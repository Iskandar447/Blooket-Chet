# Blooket-Chet — Crypto Panel

A standalone, local demo dashboard with a responsive interface.

## Files
- `index.html` — page structure
- `style.css` — responsive dark UI
- `script.js` — tabs, demo crypto actions, local preferences, basic page metadata observer

## Run locally
Open `index.html` in a modern browser.

## GitHub Pages
1. Upload all files to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then Save.

## Safety and limitations
This is a demo dashboard. It does not alter Blooket balances, communicate with game servers, automate gameplay, or bypass game rules. Prices and transactions are sample values only. The page observer reads only ordinary document metadata and visible text length.
